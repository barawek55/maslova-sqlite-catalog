# Мой каталог

Учебное приложение Android на Java и SQLite. Студент: Маслова Ксения Сергеевна, группа Т-433901-НТ.

На главном экране категории загружаются из таблицы `categories`. После выбора категории приложение запрашивает связанные товары из таблицы `products` и показывает название, описание и цену. Подготовленная база находится в `app/src/main/assets/catalog.db` и копируется во внутреннее хранилище при первом запуске.

Откройте папку проекта в Android Studio и запустите приложение на устройстве с Android 6.0 или новее.
